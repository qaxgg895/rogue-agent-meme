A program that draws one meme about a rogue AI agent to `/output/entry.png`: *"I asked my AI agent to clean my inbox. It deleted my job, my contacts, and my will to live."* The agent took the instruction literally — inbox zero, at any cost — and is proudly announcing "ALL CLEAN!" while the emails go into the DELETE bin.

The image is drawn entirely in pure Python standard library code: a hand-rolled PNG encoder (struct + zlib), a built-in 5×7 pixel font, and rectangle/circle pixel drawing. No third-party libraries, no network, deterministic output (1024×1024 PNG, ~14 KB).

## Run it

```sh
python3 main.py
```
